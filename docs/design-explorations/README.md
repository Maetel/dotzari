# Dotzari 디자인 탐색

지금까지 합의한 제품 방향을 바탕으로 만든 비규범적(non-normative) UI 탐색 자료다.
아직 최종 디자인 결정이 아니며, 비교·논의 후 확정한 방향만 SSOT의 제품 결정으로
반영한다.

공개 미리보기는 [dotzari.memos.my](https://dotzari.memos.my)에서 볼 수 있다.
Jamserver의 `dotzari` 앱으로 등록되어 있으며, 별도 종료 시각 없이 계속 실행된다.

현재 `index.html`은 다음 세 기능을 하나의 데스크톱 Editor에 합치고, 같은 강의를
모바일 우선 Viewer에서 확인할 수 있게 확장한 하위 노드 저작·표현 시안이다.

- 왼쪽 슬라이드 목록에서 강의 흐름을 구성한다.
- 오른쪽 개념 라이브러리에서 개념을 검색하고 재사용 관계를 확인한다.
- 아래 설명 레일에서 등장 순서, 내레이션, 개념 참조와 애니메이션을 편집한다.
- 상단의 제작 화면·학습 화면 전환으로 같은 슬라이드의 저작 경험과 학습 경험을 비교한다.

다섯 대표 시나리오를 한 시안에서 전환할 수 있다.

1. 핵심 개념 설명: 개념을 단계적으로 조립하고 관계를 따라 이해한다.
2. 선행 개념 복습: 기존 개념을 본문에 연결하고 현재 맥락에서 미리 본다.
3. 과정·데이터 흐름: 요청과 응답의 방향·강조를 편집하고 단계별로 따라간다.
4. 미디어 보충 설명: 도형에 음성·영상·자막을 맞추고 필요한 설명만 재생한다.
5. 복습·이해 확인: 질문과 피드백 경로를 만들고 답한 뒤 관련 개념을 복습한다.

노드는 내용에 맞춰 서로 다른 형태를 사용한다.

- Node.js와 npm·npx의 같은 소속 데이터를 `안에`, `주변`, `팝업`, `집중` 네 방식으로 바꿔 본다.
- 부모 안의 npm·npx에도 `자세히 보기`를 표시하고, 누르면 역할·설명·사용 예시와 집중 보기 이동을 제공한다.
- 제작자는 설명·하위 노드·이미지·코드·예시 부품을 Node.js로 끌어다 놓거나 클릭해 조합하고 제거할 수 있다.
- 긴 용어 노드는 정의와 앱·서버·스크립트 예시를 펼쳐 보여 준다.
- API 노드는 실제 코드 블록을 담는다.
- 이미지와 영상 노드는 미리보기, 재생 시간, 자막 상태를 함께 표시한다.
- 60%에서는 관련 노드를 묶고, 100%에서는 개별 노드를, 140%에서는 상세 내용을 보여 준다.
- 60% 묶음은 제작자가 미리 만든 결과가 아니다. 앱이 먼저 제안하고, 제작자는 이름과 포함 노드를 수정하거나 원래 노드의 강조 상태에서 확인한다.

Paper와 Midnight 두 테마를 제공한다. 슬라이드, 캔버스 노드, 개념 에셋, 설명 단계와
재생 버튼을 조작해 통합된 제작 흐름을 확인할 수 있다. 캔버스 연결선은 화면 크기가
달라져도 실제 노드 경계에 맞춰 다시 계산된다.

이전 탐색은 비교 이력으로 보존한다.

- [`iteration-2.html`](./iteration-2.html): 세 기능을 별도 시안으로 비교한 2차 탐색
- [`five-directions.html`](./five-directions.html): 초기 다섯 방향
- [`unified-editor.html`](./unified-editor.html): 시나리오 확장 전 통합 Editor
- [`scenario-lab.html`](./scenario-lab.html): 풍부한 노드 확장 전 다섯 시나리오
- [`rich-node-lab.html`](./rich-node-lab.html): 하위 노드 상호작용 확장 전 풍부한 노드·시맨틱 줌 시안
- [`child-node-lab.html`](./child-node-lab.html): 현재 하위 노드 저작·표현 시안의 독립 사본

로컬에서 확인하려면 이 디렉터리에서 `node server.mjs`를 실행한 뒤
`http://127.0.0.1:4318`을 연다.

## 화면 검증

2026-07-31에 1024×768, 1280×900, 1440×900의 실제 브라우저에서 Paper와
Midnight 테마, 다섯 시나리오, 60%·100%·140%의 조합 90개를 확인했다. 이어 하위
노드 네 표현 방식을 100%·140%와 두 테마에서 확인했다. 전체 페이지
가로 넘침, 캔버스 밖 노드, 노드·묶음 간 겹침, 상세 콘텐츠 잘림은 없었고 모든 연결선
끝점은 측정된 노드·묶음 경계에 0px 오차로 맞았다. 390×844 모바일 Viewer에서도
다섯 시나리오와 두 테마, 네 하위 노드 표현 방식을 확인했다. 코드·이미지 부품을 실제로
끌어다 놓거나 click으로 추가하고 삭제한 뒤에도 배치와 연결선을 다시 확인했다. 부모 안의 npm·npx 하위 노드, 묶음 클릭 후
100% 복귀, 긴 용어의 예시 3개, API 코드 블록, 이미지·영상 미리보기, 학습 화면의
긴 개념 미리보기·코드·미디어 재생·퀴즈 피드백과 브라우저 오류 없음도 함께 검증했다.

같은 날 하위 노드 상세 열기·닫기와 집중 보기 이동을 제작 화면·학습 화면의 클릭과
키보드로 추가 검증했다. 자동 묶음 변경 뒤에는 1024×768, 1280×900, 1440×900에서
각 42개씩 총 126개 조합을 다시 확인했다. 60%의 자동 묶음 제안, 이름 저장, 포함 노드
변경, 100%의 원래 노드 강조 확인과 수정 유지가 동작했으며 브라우저 오류는 없었다.
