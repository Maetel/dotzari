# Dotzari 라이브러리 구현 계획

## 목표

현재 학습 화면 기준안을 다른 앱에서도 사용할 수 있는 패키지로 구현하고, 이 저장소의
공식 데모 앱은 실제 패키지를 import한 뒤 더미 강의 데이터만 주입한다. 디자인 탐색 HTML을
복사해 운영하지 않는다.

## 패키지 경계

| 위치 | 책임 | 포함하지 않는 것 |
|---|---|---|
| `@dotzari/design-system` | 강의 데이터 타입, 검증, 스텝 평가, 측정값 기반 레이아웃, 캔버스 기하와 상태 | Svelte, DOM 렌더링, 더미데이터 |
| `@dotzari/design-system-svelte` | 챕터·스텝 진행, 풍부한 노드, 학습 캔버스와 Viewer 조합 | 앱 전용 문구, 샘플 강의 데이터 |
| `@dotzari/design-system-demo` | 24개 노드 더미 강의, 테마 전환, 라이브러리 사용 예시와 상태 검증 | 라이브러리 내부 로직 복제 |

현재 패키지명은 workspace의 구현 이름이다. 외부 registry에 공개할 이름과 지원 버전은
제품 사양의 Q-005에서 별도로 정한다. 그 전에도 빌드 산출물과 명시적인 export를 통해 다른
workspace나 앱에서 사용할 수 있게 유지한다.

## 첫 번째 공개 모델

```text
Lesson
├─ Chapter[]
│  └─ stepIds[]
├─ Step[]
├─ Node[]
└─ Edge[]
```

- 모든 엔티티는 배열 위치와 별개인 안정적인 `id`를 가진다.
- 노드는 자신이 처음 나타나는 `stepId`, 같은 열의 순서, 너비와 콘텐츠를 가진다.
- 노드 콘텐츠는 요약, 수치, 아코디언, 시각 자료, 경로, 체크리스트, 표, 인용, 코드를
  구분된 데이터로 표현한다.
- 연결은 시작·도착 노드와 처음 나타나는 스텝을 가진다.
- Viewer는 현재 스텝에서 보이는 노드·연결, 현재 챕터, 앞뒤 스텝을 코어 함수로 계산한다.

## 레이아웃 원칙

1. 스텝은 왼쪽에서 오른쪽으로 열을 만든다.
2. 컴포넌트가 실제 노드 높이를 측정해 코어 레이아웃 함수에 전달한다.
3. 코어는 측정값으로 노드 위치, 월드 크기와 챕터 경계를 계산한다.
4. 연결선은 최종 노드 경계에서 다시 계산한다.
5. 캔버스 배경은 월드에 포함되어 콘텐츠와 함께 움직인다.
6. 사용자가 드래그를 놓으면 즉시 멈추며 스냅이나 추가 관성을 적용하지 않는다.

## 구현 순서

### 1단계 · 코어 세로 조각

- 강의·챕터·스텝·풍부한 노드 타입
- 참조 무결성 검사
- 현재 스텝 평가와 앞뒤 이동
- 측정값 기반 오른쪽 진행 레이아웃
- 코어 단위 테스트

### 2단계 · Svelte Viewer

- 챕터·스텝 통합 인디케이터
- 측정되는 풍부한 노드 카드
- 챕터 경계와 연결선을 가진 학습 캔버스
- 확대·축소, 배경과 함께 움직이는 드래그
- 이전·다음 이동과 노드 선택 설명

### 3단계 · 긴 콘텐츠

- 코드·표·이미지 공통 전용 보기 틀
- 전체 내용, 설명과 함께 보기, 구조 지도의 세 모드
- 노드 내부 스크롤과 캔버스 동작 분리

### 4단계 · 데모와 소비자 문서

- 3개 챕터, 7개 스텝, 24개 노드의 더미 강의
- Paper·Midnight와 모바일·데스크톱 검증
- 패키지 import 예제와 props·이벤트 문서
- 데모 정적 빌드 배포

### 5단계 · Editor 연결

- 같은 `Lesson` 모델로 챕터 제목과 스텝 소속 편집
- 노드 생성·이동·콘텐츠 편집
- 저장·복원과 명령 이력

## 첫 구현 완료 조건

- 데모가 HTML 탐색 코드를 import하거나 복사하지 않고 Svelte 패키지만 사용한다.
- 더미데이터를 다른 `Lesson` 객체로 바꿔도 컴포넌트 코드를 수정할 필요가 없다.
- 24개 노드가 단계별로 나타나고 챕터·스텝 인디케이터와 캔버스 경계가 함께 갱신된다.
- 아코디언 높이 변화 뒤 노드, 연결선과 챕터 경계가 다시 계산된다.
- 확대·축소와 드래그가 동작하고 놓은 뒤 추가 이동하지 않는다.
- 코어 테스트, 두 패키지 타입 검사, 데모 빌드와 실제 브라우저 검증이 통과한다.
